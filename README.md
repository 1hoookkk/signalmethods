# TRENCH Authoring

This repository is the focused workspace for creating, inspecting, and
validating packed filter bodies.

It contains the workstation UI, direct authoring tools, cascade inspectors,
source references, recipes, and tests for authoring outputs. It does not contain
the audio plugin or real-time runtime implementation.

Start with [SCOPE.md](SCOPE.md), then [ARCHITECTURE.md](ARCHITECTURE.md).
