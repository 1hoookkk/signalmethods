# TRENCH — UX acceptance script (Gate D, human, in FL)

The machines prove contracts; this proves feel. Run in FL Studio on a real
project, ~15 minutes, before any release tag. Every line is pass/fail — a
fail is a verdict, write it down in the session notes.

## First contact (fresh instance, no manual)
- [ ] Drop on a playing track: within 5 seconds you understand MORPH is the
      instrument (grab it, hear it, see the curve move).
- [ ] The lower plate is quiet — nothing open, nothing asking for attention.
- [ ] BODY name, MORPH, Q, KEY, MIX all readable at arm's length, 100% scale.

## Gesture law (every control, no exceptions)
- [ ] Wheels: drag is absolute and instant; Shift is fine; double-click
      resets; scroll steps. No gesture surprises anywhere.
- [ ] Knobs: drag up/down, Shift fine, double-click reset, scroll — identical
      feel on PREAMP / GRIT / SLAM / AMOUNT.
- [ ] Every selector opens on one click and closes on choice. Nothing needs
      a second attempt.

## The rooms
- [ ] GAIN / MOVEMENT / SOURCE each open in place; switching rooms never
      moves the selector or reflows anything above it.
- [ ] Choosing the open room again closes it back to the quiet plate.
- [ ] No filter body: MORPH/Q/GRIT/MOTION visibly step back; SLAM and MIX
      stay alive. Nothing pretends.

## Resample (make-or-break — run blind on drums AND a pad)
- [ ] Play a hit, press RESAMPLE seconds later: it kept THE hit your ear
      remembers — right start, right tail.
- [ ] The track NEVER changes because you grabbed.
- [ ] USE AS INPUT: the takeover is obvious (amber), reversible in one
      click, loops without a click or thump.
- [ ] Press with nothing played: the glass says NOTHING TO RESAMPLE.
- [ ] Drag the wave into the FL channel rack: the file is the take, exact.
- [ ] Save project while feeding, reopen: it sounds identical.

## Preset travel
- [ ] Switching bodies mid-playback: glass updates instantly, audio follows
      without a pop, settings (MORPH/Q/MIX/SLAM) stay put.
- [ ] Sweep 10 bodies fast by hover-audition: no hangs, no stale curve.

## Endurance
- [ ] Two instances in one project behave independently.
- [ ] Close/reopen the editor 5 times fast: state intact, no flicker of a
      wrong room, no dead controls.
- [ ] Automate MORPH and MIX from FL: face follows, no fights with the mouse.
