# Recipes

This directory contains authored preset-making data.

- `catalogue.json` indexes the retained recipe families.
- `cubes/`, `hero/`, `vocal/`, and the other data directories contain authored source material.
- `profiles/` contains reusable authoring profiles.
- `postures/user_postures.json` contains the current user posture state.
- `tables/` contains cited source tables used by recipes.

Factory bytes, measurements, captures, patents, and manuals belong in `../evidence/`.
Compiled shipping bodies belong in `../plugin/presets/bodies/`.
