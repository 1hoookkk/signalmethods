# Evidence

This is the sole retained evidence and reference tree.

- `factory-data/` contains preserved source bytes and decoded corpora.
- `measurements/` and `research-results/` contain retained observations and derived results.
- `captures/` contains source and comparison recordings.
- `manuals/` and `patents/` contain external references.
- `MANIFEST.json` records each retained file's SHA-256, size, category and pre-cleanup source path where known.

Evidence does not silently define editor behavior. Active synthesis behavior lives in `../native/core/`; authored data lives in `../recipes/`; shipping bodies live in `../plugin/presets/`.
