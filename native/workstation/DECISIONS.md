# Workstation decisions

## LPC envelope and corner peaks

- ENVELOPE follows the preserved Spectrogram README's stated sequence: order-12 LPC, synthesis-filter impulse response, then FFT magnitude; an authored bell-filter response is not the input envelope.
- Resample speech to 11,025 Hz with MATLAB's antialiasing FIR before LPC; sources below that rate retain their rate, and playback is not resampled by this analysis operation.
- Retain the specification's 60 ms cursor window and selected analysis window; the README does not specify its LPC preprocessing or impulse-response length, so those details are implementation choices, not verified binary equivalence to the SGI program.
- Remove the slice mean, use MATLAB `lpc` with order 12 and prediction-error gain, and FFT an impulse response of FFT SIZE samples; retain measured amplitude rather than normalizing each envelope to its tallest peak.
- If a deterministic tone makes the order-12 covariance solution singular or unstable, retry its Yule-Walker solution with a 1e-10 relative diagonal regularizer; a valid audible tone must not silently become an empty envelope.
- Read the visible envelope maxima near the LPC conjugate poles; estimate bandwidth from the matching pole radius, then order peaks from low to high frequency so vowel formants feed corresponding SOS rows.
- Keep the full LPC envelope and up to six peak estimates; the five strongest peaks supply the five editable resonant rows, in frequency order, because law 5 reserves row 6 for CEILING.
- Peak measurements are source data; the corner chord remains the editable truth, with the specification's 0.25-semitone pole width and 4-semitone zero width applied before fitting and compilation.
- ENVELOPE selects SPEECH; selecting BELLS leaves ENVELOPE, so the displayed analysis and the reader cannot silently refer to different models.
- Show the analysis only up to its actual Nyquist frequency and place the 3D peak markers at the envelope's height; do not extend low-rate LPC results to 20 kHz.
- Silence clears the peaks and disables a new read through an empty slice chord, so a previous vowel cannot be saved under a silent cursor position.
- The user's resampling request concerns LPC analysis of sound, not sampling the MORPH x Q corner space; the mistakenly added grid operation was removed.

Sources: [preserved Spectrogram README](../../evidence/research-results/emu-sgi-1993/spectrogram/extracted/README), [MATLAB lpc](https://www.mathworks.com/help/signal/ref/lpc.html), [MATLAB resample](https://www.mathworks.com/help/signal/ref/resample.html).

The full workstation acceptance and remaining build decisions are still being completed; this record does not assert that the whole application has passed acceptance.
